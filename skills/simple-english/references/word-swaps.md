# 從冗餘詞到平實詞的替換

此表是我們自己的，不是 ASD 詞典。它將 AI 生成文件過度使用的詞對映到平實替代。如果詞不帶事實，刪除它而非替換。

| 冗餘詞 | 改為 |
|---|---|
| leverage、utilize | use |
| in order to | to |
| prior to | before |
| ensure | make sure that |
| it is worth noting that | （刪除） |
| it's important to | （刪除，然後陳述事實） |
| simply、just、easily、seamless、seamlessly、effortlessly | （刪除） |
| robust、powerful、comprehensive、performant | （刪除，或給出可測量屬性） |
| functionality | function、feature |
| enables you to、allows you to | you can |
| is designed to、aims to | （刪除，然後說它做什麼） |
| facilitate | help、make possible |
| dive into、delve into | read、examine |
| when it comes to | for |
| in the event that | if |
| due to the fact that | because |
| as needed、as necessary | （陳述條件） |
| and/or | 選一個，或寫"X, or Y, or both" |
| e.g. / i.e. / etc. | for example / that is / （列出專案） |
| gracefully handles | （說它做什麼："retries three times, then stops"） |
| out of the box | by default |
| under the hood | internally |
| blazingly fast | fast（給出數字）/（刪除） |
| streamline | make simpler、make faster |
| plethora、myriad | many |
| addresses the issue、tackles | corrects the fault、removes the error |
| pivotal、crucial、crucially、paramount | important |
| tapestry、testament、synergy | （刪除） |
| interplay | interaction（或刪除） |
| intricate | complex |
| vibrant、nuanced、multifaceted | （刪除，或列出部分） |
| realm、landscape（隱喻） | area |
| groundbreaking、cutting-edge、state-of-the-art、innovative、unprecedented | new（或刪除） |
| transformative、game-changer | （刪除，然後說改變了什麼） |
| revolutionize | change |
| showcase、underscore、emphasize | show |
| foster、empower、bolster | help、support、let |
| harness | use |
| enhance | improve |
| elevate | increase |
| furthermore、moreover | also |
| in conclusion、in summary、at the end of the day | （刪除） |
| embark、endeavor | start、try |
| meticulous、meticulously | careful、carefully |
| holistic | full |
| paradigm | model |
| navigate（隱喻） | go to |
| boasts | has |
| nestled、in the heart of | （刪除，然後給出位置或事實） |
| bustling | busy |
| that being said、notwithstanding | but |
| I hope this helps、let's dive in | （刪除） |

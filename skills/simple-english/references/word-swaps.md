# 从冗余词到平实词的替换

此表是我们自己的，不是 ASD 词典。它将 AI 生成文档过度使用的词映射到平实替代。如果词不带事实，删除它而非替换。

| 冗余词 | 改为 |
|---|---|
| leverage、utilize | use |
| in order to | to |
| prior to | before |
| ensure | make sure that |
| it is worth noting that | （删除） |
| it's important to | （删除，然后陈述事实） |
| simply、just、easily、seamless、seamlessly、effortlessly | （删除） |
| robust、powerful、comprehensive、performant | （删除，或给出可测量属性） |
| functionality | function、feature |
| enables you to、allows you to | you can |
| is designed to、aims to | （删除，然后说它做什么） |
| facilitate | help、make possible |
| dive into、delve into | read、examine |
| when it comes to | for |
| in the event that | if |
| due to the fact that | because |
| as needed、as necessary | （陈述条件） |
| and/or | 选一个，或写"X, or Y, or both" |
| e.g. / i.e. / etc. | for example / that is / （列出项目） |
| gracefully handles | （说它做什么："retries three times, then stops"） |
| out of the box | by default |
| under the hood | internally |
| blazingly fast | fast（给出数字）/（删除） |
| streamline | make simpler、make faster |
| plethora、myriad | many |
| addresses the issue、tackles | corrects the fault、removes the error |
| pivotal、crucial、crucially、paramount | important |
| tapestry、testament、synergy | （删除） |
| interplay | interaction（或删除） |
| intricate | complex |
| vibrant、nuanced、multifaceted | （删除，或列出部分） |
| realm、landscape（隐喻） | area |
| groundbreaking、cutting-edge、state-of-the-art、innovative、unprecedented | new（或删除） |
| transformative、game-changer | （删除，然后说改变了什么） |
| revolutionize | change |
| showcase、underscore、emphasize | show |
| foster、empower、bolster | help、support、let |
| harness | use |
| enhance | improve |
| elevate | increase |
| furthermore、moreover | also |
| in conclusion、in summary、at the end of the day | （删除） |
| embark、endeavor | start、try |
| meticulous、meticulously | careful、carefully |
| holistic | full |
| paradigm | model |
| navigate（隐喻） | go to |
| boasts | has |
| nestled、in the heart of | （删除，然后给出位置或事实） |
| bustling | busy |
| that being said、notwithstanding | but |
| I hope this helps、let's dive in | （删除） |
